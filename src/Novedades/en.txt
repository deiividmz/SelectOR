Switches along your itinerary|In SelectOR server rooms, with an itinerary in the road book, the switches ahead are set automatically as you approach. If another train needs them first (scheduled services first, then passenger and then freight trains), SelectOR tells you to wait.
Switches for everyone|In SelectOR server rooms any player can throw switches from the map (Ctrl+9).
Rooms for any route|The administrator can create rooms with no route assigned: the session uses the route of the first player to join.
Scheduled services|The «Scheduled» board shows the train with the same 2D view as Services, in tidier rows, and the end time always in full.
